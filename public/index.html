Implementation caveats

    Step-by-step exactness guide

    1. Historical branch creation

    Exact path without webhooks: import retained GitHub Enterprise audit-log Git events for branch ref creation, or use an existing audit-log stream. If the event is outside retention and was not streamed, exact history cannot be reconstructed from Git commits.

    1. Ask an enterprise admin for audit-log API access with read:audit_log.
    2. Run node scripts/import-github-audit-log.js --enterprise ENTERPRISE --repo OWNER/REPO --since YYYY-MM-DD.
    3. The importer keeps branch create rows and writes normalized create records to data/runtime/github-webhooks.ndjson.
    4. If no retained row exists, label the row first_commit_fallback or pr_created_fallback.

    2. Copilot lines per PR/commit

    Exact path without Copilot metrics: capture provenance when the AI edit is made. Post-hoc GitHub PR diffs show changed lines, but not which lines were generated by Copilot.

    1. Wrap the demo agent or editor workflow so every accepted AI patch records repo, branch, file, added/deleted LoC, user, and session id.
    2. After commit/PR creation, attach commit_sha and pr_number to the provenance row.
    3. Post rows to POST /ingest/ai-provenance or append to data/runtime/ai-provenance.ndjson.
    4. If no provenance was captured at edit time, show only directional AI usage or manual attestation, never exact per-PR attribution.

    3. Live custom-agent traces

    Exact path without an OTel collector: have the custom agent emit simplified trace JSON directly to this demo's trace endpoint. Without runtime instrumentation, traces can only be inferred from PRs, commits, or bot accounts.

    1. Run node scripts/emit-agent-trace.js --agent AGENT --user USER --repo OWNER/REPO --branch BRANCH --tools edit,test or emit the same JSON from the agent runtime.
    2. For each tool call, send a child execute_tool span with tool name, status, and duration.
    3. On completion, send the final span status, duration, token counts, and commit/PR identifiers.
    4. If the agent cannot emit runtime events, label the row as inferred activity instead of a live trace.

    Local ingestion endpoints

    POST /webhooks/github            GitHub create/push/pull_request payloads
POST /otel/v1/traces         OTLP JSON or simplified span JSON
POST /ingest/copilot-usage   Copilot users-1-day NDJSON/JSON rows
POST /ingest/ai-provenance   Exact edit-time AI LoC provenance rows
POST /api/settings/github-sync Live GitHub org/repo PR sync
GET  /api/model              Full normalized dashboard model
